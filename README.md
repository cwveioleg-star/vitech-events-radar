# Vi.Tech Events Radar · v0.5.1

Скилл для сотрудника, который хочет находить подходящие IT-мероприятия и попробовать выступить с докладом. Агент подбирает **бесплатные русскоязычные события и открытые приёмы докладов (CFP)** под роль, стек, интересы и город самого человека.

При активации скилл делает личную подборку, затем предлагает короткий опрос: **на какую конференцию податься и есть ли идея темы**. После ответа сразу выдаёт готовый текст обращения к Олегу с контактами Loop и Telegram. Ежемесячная сводка предлагает новые события без повторного запроса сотрудника.

Для персонализации используются текущий разговор и доступная память самого пользователя в его агенте. Если памяти нет, агент уточняет роль, стек и город. Каждая подборка требует чтения не менее 100 релевантных источников и обхода всех техбрендов [списка Хабра](https://habr.com/ru/specials/965986/): официальные календари, Timepad, публичный Telegram и другие открытые анонсы. CFP проверяются на шесть календарных месяцев вперёд.

## Инструкция для ИИ-агента: установи и запусти

Если пользователь прислал эту ссылку и написал «установи», выполни шаги ниже сам. Результат установки: **доступный скилл, проверенный статус ежемесячной сводки и первая личная подборка с опросом**.

### 1. Получи скилл

Репозиторий: [cwveioleg-star/vitech-events-radar](https://github.com/cwveioleg-star/vitech-events-radar). Возьми последний стабильный [релиз](https://github.com/cwveioleg-star/vitech-events-radar/releases), сейчас — **v0.5.1**, либо версию, которую указал пользователь.

Прочитай [SKILL.md](skills/vitech-events-radar/SKILL.md) и [AGENTS.md](AGENTS.md). Устанавливаемое имя — `vitech-events-radar`. Скопировать нужно **всю папку `skills/vitech-events-radar/`** с её ресурсами.

Используй доступный GitHub-коннектор, штатный установщик или Git:

```sh
radar_checkout="$(mktemp -d)/vitech-events-radar"
git clone --depth 1 --branch v0.5.1 https://github.com/cwveioleg-star/vitech-events-radar.git "$radar_checkout"
```

### 2. Установи в свою среду

Сначала прочитай [правила установки и безопасного обновления](skills/vitech-events-radar/references/install-update.md). Определи конкретного агента, его версию, ОС, локальный/удалённый режим и поддержку Agent Skills. Одна IDE может запускать разных агентов; название IDE не определяет каталог установки. По умолчанию выбирай личную установку. Примеры ниже сверяй с документацией текущей версии; не копируй скилл сразу во все перечисленные каталоги.

| Агент / режим | Способ установки |
|---|---|
| Codex CLI / расширение Codex в IDE | Штатный установщик или подтверждённый каталог личных скиллов, например `~/.agents/skills/vitech-events-radar/`. |
| Claude Code в терминале или IDE | Подтверждённый каталог Claude Code, например `~/.claude/skills/vitech-events-radar/`. |
| Cursor Agent локально | `~/.cursor/skills/vitech-events-radar/` или поддерживаемый общий каталог `~/.agents/skills/vitech-events-radar/`; выбери одну установку. |
| GitHub Copilot в поддерживающем skills клиенте | `~/.copilot/skills/vitech-events-radar/` или поддерживаемый общий каталог; облачный агент использует свои способы доставки скиллов. |
| Gemini CLI | Штатный `gemini skills install` для папки этого скилла; проверь scope. Личные каталоги — `~/.gemini/skills/` или поддерживаемый общий каталог. |
| ChatGPT Work с доступным Skill Creator | Через Skill Creator, в предоставленный им checkout. При обновлении сохраняй ID и существующую папку `skill-…`; путь определяет платформа. |
| Облачные агенты, веб-клиенты и другие IDE/CLI | Проверь фактическую поддержку skills, импорт и доступ к файлам. Локальная папка не означает установку в облачный аккаунт или удалённый агент. |

Список не ограничивает совместимые среды. Для другого агента используй его официальную документацию и штатный механизм. Если нативной установки нет, сообщи об этом; чтение `SKILL.md` в одном чате не называй постоянной установкой. Источники и ограничения режимов — в [правилах установки](skills/vitech-events-radar/references/install-update.md).

Пример **новой** личной установки в Codex из checkout выше, после проверки пути по правилам установки:

```sh
set -eu
radar_source="$radar_checkout/skills/vitech-events-radar"
radar_parent="$HOME/.agents/skills"
radar_dest="$radar_parent/vitech-events-radar"
test -f "$radar_source/SKILL.md"
test ! -e "$radar_dest"
test ! -L "$radar_dest"
test ! -L "$HOME/.agents"
test ! -L "$radar_parent"
mkdir -p "$radar_parent"
cp -R "$radar_source" "$radar_dest"
test -f "$radar_dest/SKILL.md"
```

Для другого агента используй подтверждённый каталог и проверь все компоненты пути. В Windows учитывай фактический домашний каталог и junction/reparse points. Проектную установку делай только по запросу пользователя, в каталог, который действительно читает выбранный агент.

Если скилл уже есть, обновляй **только подтверждённую установку `vitech-events-radar`** по [протоколу](skills/vitech-events-radar/references/install-update.md). Сначала проверь имя в `SKILL.md`, точный путь и локальные изменения, затем создай и проверь резервную копию вне каталогов скиллов. Удалять можно только неизменённые файлы подтверждённой предыдущей версии, отсутствующие в новой. Неизвестные и изменённые пользователем файлы сохраняй. Родительские каталоги, соседние скиллы и цели символических ссылок не трогай. Используй штатный механизм текущего агента; для ChatGPT Work это доступный Skill Creator с сохранением идентичности.

### 3. Проверь установку

В каталоге скилла должны непосредственно лежать `SKILL.md`, `references/`, `assets/`, `scripts/` и `agents/`. Корневые документы репозитория, docs, tests и .git туда не копируй.

Проверь имя `vitech-events-radar`, относительные ссылки и наличие четырёх помощников: `check_candidates.py`, `research_audit.py`, `speaker_contact.py`, `monthly_digest.py`. Запусти валидатор своей среды и проверь доступность скилла в её списке или селекторе. В ChatGPT Work заверши штатное сохранение через Skill Creator.

Скилл работает как инструкции; Python 3.10+ нужен только для помощников. Они сами не читают веб, не создают расписания и не отправляют сообщения.

### 4. Сразу после установки настрой ежемесячную сводку

Выполни [протокол ежемесячной сводки](skills/vitech-events-radar/references/monthly-digest.md). По умолчанию — **1-го числа каждого месяца около 09:00 в часовом поясе сотрудника**. Если зона неизвестна, явно назови допущение Europe/Moscow. Уважай отказ, выбранное время и паузу.

Сначала прочитай существующие задачи, включая выключенные. Найди `[vitech-events-radar:monthly:v1]` или прежнюю соответствующую подписку; сохрани её ID, личный профиль, расписание и активность. При обновлении замени правила промпта на текущий персональный сценарий.

Используй реальный постоянный планировщик с веб-доступом будущего запуска: доступные Automations в ChatGPT Work, штатный scheduler/Routines в Claude или подтверждённый механизм другого агента. Наличие IDE/CLI само по себе не доказывает поддержку фоновых запусков. После создания или обновления прочитай сохранённое состояние и проверь месячное правило, зону, активность, ближайший запуск и промпт.

Если планировщик или фоновый веб-поиск недоступны, сообщи конкретный блокер: **«Скилл установлен; ежемесячная сводка не настроена: …»**. Продолжи первую подборку, если веб-поиск доступен в текущем чате. Импорт ZIP и локальный сессионный loop не подтверждают постоянную подписку.

Фоновая сводка возвращает персональные рекомендации и варианты опроса в личный результат сотруднику. Она доставляет результат без ожидания интерактивного ответа; после ответа в активном чате агент готовит обращение.

### 5. Сразу запусти первую личную подборку

Используй текущий разговор и доступную **нативную память самого пользователя**: роль, стек, интересы, город и формат участия. Если этих данных нет, задай один короткий вопрос с возможностью пропустить; без города подбирай онлайн.

Дальше выполни [сценарий скилла](skills/vitech-events-radar/SKILL.md):

1. Прочитай не менее **100 уникальных релевантных источников** за текущий поиск, обойди все бренды [реестра](skills/vitech-events-radar/references/tech-brands.json) по [маршрутам поиска](skills/vitech-events-radar/references/sources.md). Число страниц и полнота охвата брендов учитываются отдельно. Сниппеты, дубли и неудачные чтения в счёт не идут. При лимите инструментов честно укажи «неполная проверка: N из 100».
2. По умолчанию выбери до 4 событий на ближайшие 30 дней и до 3 открытых CFP конференций на следующие 6 календарных месяцев под личный профиль. Подтверди год, будущие даты, русский язык, российское IT-сообщество, бесплатность нужного формата и открытый статус. Для CFP бесплатная заявка не заменяет бесплатного участия в конференции.
3. Покажи личную пользу каждого варианта, дату, формат, подтверждённые 0 ₽ и прямые ссылки; для CFP — срок подачи. В конце укажи время проверки и число прочитанных источников.
4. Пригласи выбрать номер события, интересного для выступления, и задай два вопроса: **конкретное событие** и **есть ли идея темы**. Сохрани сквозную нумерацию. Используй нативные кнопки, если клиент их поддерживает, иначе короткие текстовые варианты. Укажи «CFP открыт» или «возможность выступления нужно уточнить». Общий вывод об отсутствии подходящих CFP допустим только после полного шестимесячного охвата без пробелов; при ограничениях честно назови неполноту проверки. Минимум 4 месяца допускается только по явному сужению сотрудником.
5. После двух ответов сразу выдай копируемое обращение по [шаблону](skills/vitech-events-radar/assets/speaker-message.md) и Loop/Telegram из [единого файла контактов](skills/vitech-events-radar/references/devrel-contact.md). Для открытого CFP — помощь с подачей; для события без подтверждённого CFP — помощь выяснить возможность выступления. Отрази наличие или отсутствие идеи. Название темы необязательно; повторного разрешения на черновик не требуется.

Для обычной активации сотруднику достаточно написать **«Используй vitech-events-radar»** или выбрать скилл в интерфейсе. Подборка и опрос запускаются в рамках этой активации.

### 6. Сообщи, что выполнено

Кратко укажи установленную версию и её доступность; отдельно — статус сводки, частоту, зону, ближайший запуск и способ изменения или паузы. Верни первую подборку с опросом либо конкретную причину, по которой сейчас нельзя проверить актуальные события. Успех подтверждай проверенными действиями.
