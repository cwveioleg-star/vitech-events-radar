# Изменения

## 0.7.0 — 16.10.2026

Исправлен сценарий докладчика по issue #1. Цена разделена на free_for_attendee/free_for_speaker: платные слушателям конференции допустимы при подтверждённом бесплатном участии принятого спикера. Открытый CFP и подтверждённый маршрут внешних докладов ищутся на 6 календарных месяцев; вечеринки, закрытые программы и неизвестная возможность выступления не попадают в опрос. Исходные номера карточек сохраняются после фильтрации.

Добавлен короткий список организаторов CFP; рейтинг работодателей Хабра и JSON-аудит стали необязательными. Аудитор отклоняет сокращение полного реестра более чем вдвое. Платформенные инструкции вынесены в отдельные адаптеры; Claude Code описывает AskUserQuestion, /schedule list/update, облачные routines и копируемый блок. Добавлена проверка цены/доступности конкретного билета Timepad по HTML/API. Ranking подключён к основному сценарию. Подробные схемы вынесены из обычного пути чтения, повторы сокращены.

Названная тема сопоставляется с секциями/правилами; помощник требует результат такой проверки и нормализует ввод «доклад про …». Месячный самостоятельный промпт v5 использует те же правила; ID, настройки, согласие и пауза подписки сохраняются. Старые JSON-карточки с одним free требуют перехода на поля цены по роли. Установочный протокол и структура skills.sh сохранены.

## 0.6.1 — 16.10.2026

В README добавлена установка через skills.sh / `skills` CLI: одна команда для личного scope, выбор конкретного агента, режим копирования без символических ссылок, просмотр доступного скилла, проверка установки и установка фиксированного тега. Добавлены badge и пояснение автоматического учёта в каталоге skills.sh. Уточнены требования CLI и различие локальной установки и управляемого облачного импорта.

Сохранён протокол обновления с защитой локальных и неизвестных файлов: README учитывает, что CLI 1.7.2 пересоздаёт папку при повторной установке. Инструкции публикации приведены в соответствие с публичным доступом репозитория. Ресурсы скилла, поиск событий и настройки подписки не менялись.

## 0.6.0 — 15.10.2026

Обычный поиск начинается с агрегаторов и тематических запросов; ориентир 10–20 страниц без квоты, затем первоисточники выбранных кандидатов. Полный обход/100 страниц — только по отдельному запросу. Сохранены шестимесячный горизонт CFP, строгие фильтры бесплатности/языка/дат и сценарий «подборка → два вопроса → обращение». Выводы об отсутствии CFP ограничены проверенными источниками. Timepad/Telegram необязательны и заменяются официальными источниками без обхода авторизации.

Основной SKILL.md сокращён примерно вдвое, description — до условий применения. Явное согласие обязательно для создания фоновой сводки; установка, молчание и ответы о выступлении его не заменяют. Helper без согласия не выдаёт аргументы создания; старые задачи без подтверждения не изменяются автоматически. Самостоятельный промпт v4 использует посильный поиск, сохраняя ID/профиль/расписание/паузу подтверждённой подписки.

Реестр строится по текущей прочитанной странице; локальный JSON — датированный fallback. Аудитор принимает рабочий список произвольного размера; структурные тесты проверяют непустой список и уникальность вместо числа 126. Снимок не переписывается при обычной активации. Обновлены примеры, контракт помощника и проверки поведения.

## 0.5.1 — 15.10.2026

Установка выбирается по конкретному агенту, его версии, scope и фактическим возможностям. Добавлены маршруты Cursor Agent, GitHub Copilot и Gemini CLI; отделены локальные и облачные клиенты. ChatGPT Work/Skill Creator оставлен отдельным условным маршрутом.

Обновление ограничено одной подтверждённой установкой. Добавлены проверка имени и пути, запрет перехода по ссылкам, резервная копия с проверкой, сохранение локальных/неизвестных файлов и удаление только неизменённых ресурсов подтверждённой предыдущей версии. Правила вынесены в references/install-update.md и связаны с README, AGENTS и SKILL. Автоматический установщик не добавлялся; проверки исполняет агент или подходящий штатный updater.

## 0.5.0 — 15.10.2026

Поиск охватывает все 126 брендов общего списка Хабра, официальные календари, Timepad, публичный Telegram и другие открытые анонсы. Число прочитанных документов и полнота охвата проверяются отдельно. CFP ищутся на следующие шесть календарных месяцев; общий отрицательный вывод запрещён при пробелах или сокращённом горизонте.

После подборки сотрудник выбирает номер интересующего события и наличие идеи. Для открытого CFP сразу готовится обращение о помощи с подачей; для события без подтверждённого приёма — условный вопрос о возможности выступления. Месячный промпт v3 использует те же правила, сохраняя настройки подписки. Проверены 85 unit/CLI-сценариев и три независимых агентных прогона.

## 0.4.0 — 15.10.2026

Персональный сценарий сотрудника: активация → подборка → два вопроса о конференции/идее → немедленный копируемый текст и Loop/Telegram. Персонализация по доступной нативной памяти самого человека без корпоративных документов. Удалены командный/редакционный режим, работа над презентациями и старые международные примеры. Оставлен только проверенный публичный профиль компании.

Обязательны бесплатность, русский язык и российское техническое сообщество, в том числе для CFP. Минимум 100 реально прочитанных уникальных релевантных источников, расширенный список организаторов, локальный аудит охвата с честным статусом неполной проверки. Месячный промпт адаптирован к тому же сценарию; обновление сохраняет ID, профиль, время и паузу.
