# Изменения

## 0.5.1 — 15.10.2026

Установка выбирается по конкретному агенту, его версии, scope и фактическим возможностям. Добавлены маршруты Cursor Agent, GitHub Copilot и Gemini CLI; отделены локальные и облачные клиенты. ChatGPT Work/Skill Creator оставлен отдельным условным маршрутом.

Обновление ограничено одной подтверждённой установкой. Добавлены проверка имени и пути, запрет перехода по ссылкам, резервная копия с проверкой, сохранение локальных/неизвестных файлов и удаление только неизменённых ресурсов подтверждённой предыдущей версии. Правила вынесены в references/install-update.md и связаны с README, AGENTS и SKILL. Автоматический установщик не добавлялся; проверки исполняет агент или подходящий штатный updater.

## 0.5.0 — 15.10.2026

Поиск охватывает все 126 брендов общего списка Хабра, официальные календари, Timepad, публичный Telegram и другие открытые анонсы. Число прочитанных документов и полнота охвата проверяются отдельно. CFP ищутся на следующие шесть календарных месяцев; общий отрицательный вывод запрещён при пробелах или сокращённом горизонте.

После подборки сотрудник выбирает номер интересующего события и наличие идеи. Для открытого CFP сразу готовится обращение о помощи с подачей; для события без подтверждённого приёма — условный вопрос о возможности выступления. Месячный промпт v3 использует те же правила, сохраняя настройки подписки. Проверены 85 unit/CLI-сценариев и три независимых агентных прогона.

## 0.4.2 — 15.10.2026

Уточнены персонализация и документация: профиль сотрудника, поиск бесплатных русскоязычных событий, опрос и обращение после выбора. Обновлён комплект установки.

## 0.4.1 — 15.10.2026

Переписано описание GitHub и README: сначала суть личного скилла, затем инструкция ИИ-агенту по установке в свою среду, проверке, настройке месячной сводки и немедленному запуску первой подборки с опросом. Уточнены полный комплект из четырёх помощников и действия при ограничениях среды. Ресурсы и поведение самого скилла не менялись.

## 0.4.0 — 15.10.2026

Персональный сценарий сотрудника: активация → подборка → два вопроса о конференции/идее → немедленный копируемый текст и Loop/Telegram. Персонализация по доступной нативной памяти самого человека без корпоративных документов. Удалены командный/редакционный режим, работа над презентациями и старые международные примеры. Оставлен только проверенный публичный профиль компании.

Обязательны бесплатность, русский язык и российское техническое сообщество, в том числе для CFP. Минимум 100 реально прочитанных уникальных релевантных источников, расширенный список организаторов, локальный аудит охвата с честным статусом неполной проверки. Месячный промпт адаптирован к тому же сценарию; обновление сохраняет ID, профиль, время и паузу.

## 0.3.0 — 15.10.2026

Настройка одной личной ежемесячной сводки при установке, дедупликация, пауза и проверка реального расписания.

## 0.2.0 — 08.10.2026

Инструкция установки для агентов и подготовка обращения к контакту поддержки. Сценарий заменён персональным потоком в 0.4.
