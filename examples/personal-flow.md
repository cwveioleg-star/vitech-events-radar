# Синтетический личный сценарий

Это пример поведения, не реальная рекомендация или профиль сотрудника.

Сотрудник активирует скилл. В его нативной памяти: QA, API, автотесты, онлайн. Агент подбирает по этим интересам. Начинает с агрегаторов и тематического поиска, выбирает подходящих организаторов, читает первоисточники. Ориентир 10–20 страниц, без обязательной квоты и полного обхода. События ищет на 30 дней, CFP — на шесть календарных месяцев.

Агент показывает подходящие бесплатные русскоязычные события со сквозными номерами, затем приглашает выбрать номер для интереса к выступлению и ответить, есть ли идея. Открытый CFP обозначен явно; без CFP — «возможность выступления нужно уточнить».

Сотрудник выбирает «1, идеи пока нет». Для конференции с подтверждённым открытым CFP сразу получает:

```text
Олег, привет!
Хочу выступить на конференции «Тестовая конференция».
Пока нет идеи темы.
Помоги, пожалуйста, собрать фактуру и подготовиться к подаче.
Конференция: [проверенная ссылка]
CFP: [проверенная форма]
```

Если выбрано событие без подтверждённого CFP, текст сразу другой:

```text
Олег, привет!
Мне интересно выступить на событии «Тестовый митап».
Пока нет идеи темы.
Открытый приём докладов пока не подтверждён.
Помоги, пожалуйста, выяснить, возможно ли участие как спикера, и, если возможно, собрать фактуру.
Конференция: [проверенная ссылка]
```

Ссылки подставляются из карточки, Loop/Telegram — из references/devrel-contact.md. При «Есть идея» без названия — сразу «У меня уже есть идея темы». Сотрудник сам копирует и отправляет сообщение. Отказ от выбора завершает сценарий.

При нуле CFP агент ограничивает вывод проверенными источниками и шестимесячным периодом. После подборки один раз предлагает ежемесячную сводку с указанием расхода лимитов; без явного согласия её не создаёт. Включённая сводка сохраняет тот же посильный личный сценарий.
