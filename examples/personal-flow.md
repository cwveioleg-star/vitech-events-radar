# Синтетический личный сценарий

Это пример поведения, не реальная рекомендация или профиль сотрудника.

Сотрудник активирует скилл. В его нативной памяти: QA, API, автотесты, онлайн. Агент подбирает по этим интересам. Начинает с агрегаторов и тематического поиска, выбирает подходящих организаторов, читает первоисточники. Ориентир 10–20 страниц, без обязательной квоты и полного обхода. События ищет на 30 дней, возможности выступить — на шесть календарных месяцев. Цена посещения проверяется слушателю, выступления — спикеру.

Агент показывает подходящие русскоязычные события со сквозными номерами. Например, №1 — бесплатная вечеринка без докладов, №2 — платная слушателям конференция с бесплатным участием принятых спикеров и открытым CFP. В опрос попадает только №2, номер сохраняется. Открытый CFP обозначен явно; при подтверждённом маршруте внешних докладов без CFP — «возможность выступления нужно уточнить».

Сотрудник выбирает «2, идеи пока нет». Для конференции с подтверждённым открытым CFP сразу получает:

```text
Олег, привет!
Хочу выступить на конференции «Тестовая конференция».
Пока нет идеи темы.
Помоги, пожалуйста, собрать фактуру и подготовиться к подаче.
Конференция: [проверенная ссылка]
CFP: [проверенная форма]
```

Если выбрано событие с подтверждённой страницей спикерам, но без опубликованного CFP, текст сразу другой:

```text
Олег, привет!
Мне интересно выступить на событии «Тестовый митап».
Пока нет идеи темы.
Открытый приём докладов пока не подтверждён.
Помоги, пожалуйста, выяснить, возможно ли участие как спикера, и, если возможно, собрать фактуру.
Конференция: [проверенная ссылка]
Спикерам: [проверенный маршрут]
```

Ссылки подставляются из карточки, Loop/Telegram — из references/devrel-contact.md. При «Есть идея» без названия — сразу «У меня уже есть идея темы». Сотрудник сам копирует и отправляет сообщение. Отказ от выбора завершает сценарий.

При нуле CFP агент ограничивает вывод проверенными источниками и шестимесячным периодом. После подборки один раз предлагает ежемесячную сводку с указанием расхода лимитов; без явного согласия её не создаёт. Включённая сводка сохраняет тот же посильный личный сценарий.
