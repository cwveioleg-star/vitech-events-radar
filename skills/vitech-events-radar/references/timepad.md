# Timepad: цена и доступность билета

Если WebFetch/reader пропустил цену, прочитай исходный HTML публичной страницы: данные билетов в JSON/JSON-LD или публичный виджет регистрации. Ищи билет нужного формата и текущего события, а не произвольное `price: 0` на странице.

Подтверди одновременно цену 0, доступность билета, открытый период регистрации и отсутствие обязательного промокода/закрытой категории. Например, `price: 0` вместе с `available: true` полезны, только если эти поля относятся к подходящему билету текущего выпуска. Платный офлайн не становится бесплатным из-за билета на эфир.

При доступном штатном API используй [официальную схему события](https://dev.timepad.ru/api/get-v1-events-event-id/): `ticket_types[].price`, `remaining`, `is_active`, `is_promocode_locked`, `sale_starts_at`, `sale_ends_at` и `registration_data.is_registration_open`. Нулевой `price_min` сам по себе недостаточен: бесплатная категория может быть закрыта/исчерпана. Проверяй семантику доступных полей, включая неограниченное количество билетов; отсутствующее поле не додумывай.

Сохрани URL, ID/название категории, формат, цену и факты доступности в заметках. Если нужен недоступный токен, обход авторизации или данных недостаточно, используй официальный анонс/условия организатора либо исключи карточку. API не обязателен; цену спикера проверяй в условиях спикерам, а не в билете слушателя.
