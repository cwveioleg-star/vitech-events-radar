# Личная ежемесячная сводка

Установка включает настройку одной постоянной месячной задачи сотрудника, если он не отказался. По умолчанию 1-го числа утром, ориентир 09:00 в личной IANA-зоне. Без известной зоны явно назови Europe/Moscow. Профиль — текущие роль, стек, интересы, город и форматы из его доступной нативной памяти/разговора. Язык всегда русский, события бесплатные. Если профиль неизвестен и человек пропустил уточнение — общая инженерная подборка онлайн.

## Настройка и обновление

1. Подтверди постоянный планировщик и веб-поиск именно в будущей среде, а не только в текущем чате.
2. Прочитай все существующие задачи, включая выключенные. Ищи стабильный маркер `[vitech-events-radar:monthly:v1]`, а также старую соответствующую задачу по названию. Ошибка чтения не равна пустому списку; при дублях сначала разбери совпадения.
3. Новая установка без совпадений — создай одну задачу штатным инструментом. В ChatGPT Work используй Automations: приватное чтение → create/update → повторное чтение. В Claude используй реально доступный постоянный Routines/schedule по текущей документации платформы; локальный сессионный loop не подходит. Не выдумывай поддержку cron/API.
4. При переустановке сохрани ID, профиль, время, зону и паузу. При обновлении замени только правила промпта на персональный сценарий v3, **сохранив** личные настройки; маркер дедупликации v1 остаётся прежним. Не возобновляй выключенную задачу. Для helper передай refresh_prompt=true и прочитанные existing_tasks[].profile/timezone; при отсутствии этих данных сначала восстанови их из сохранённого промпта/расписания. Не подставляй заново умолчания вместо старых предпочтений.
5. Прочитай сохранённое состояние: ID, активность, месячное правило, зону, ближайший запуск и полный промпт. Подписка существует только после подтверждённой записи. Сам импорт ZIP не выполняет hook.
6. Отдельно сообщи «файлы установлены» и проверенный статус подписки. При недоступном планировщике сообщи конкретный блокер; не утверждай создание. Доставка идёт в личный результат планировщика, уведомления зависят от приложения и ОС.

`scripts/monthly_digest.py` принимает JSON на stdin и выдаёт **план**, ничего не создаёт и не отправляет. Для нового профиля допустимы role, topics, city, formats, languages=["ru"], event_limit, cfp_limit, offer_speaker_help. Сохранять профиль в дистрибутив запрещено. platform=chatgpt/claude/other; capabilities.persistent_scheduler/web_search, lookup_succeeded, existing_tasks обязательны для решения. Выполни реальные вызовы и readback после плана. Подробности формата — в docs/MONTHLY-DIGEST-TESTS.md репозитория, если он доступен установщику.

## Поведение будущего запуска

Промпт содержит общий личный профиль и самостоятельные правила на случай недоступности файлов скилла: не менее 100 реально прочитанных уникальных релевантных источников, полный реестр брендов с Хабра, официальные календари/Timepad/публичный Telegram, проверка бесплатности/русского языка/сообщества/текущего года/регистрации. События — 30 дней, CFP — следующие 6 календарных месяцев. Проверять весь интервал и не делать общего отрицательного вывода при пробелах. При неполном охвате — N из 100, без ложного заявления об успехе.

Результат — персональные рекомендации под сотрудника. В конце приглашение выбрать номер интересующего события для выступления и два коротких вопроса о событии и наличии идеи темы. Для открытого CFP — обращение о помощи с подачей, для проверенного события без CFP — условный вопрос о возможности выступления. Статус приёма обозначать честно. Не блокируй доставку интерактивным инструментом в фоне. При отсутствии неблокирующего UI дай варианты и инструкцию ответить в обычном чате. После ответов сразу копируемое обращение с Loop/Telegram; повторное согласование черновика не требуется. Если человек отключил помощь с выступлением, не добавляй опрос/контакты.

Фоновый запуск не создаёт и не меняет расписание. Не отправляет сообщение Олегу, не регистрирует сотрудника, не делает командных рассылок и не ищет корпоративный контекст.

## Управление

Изменение времени/тем — обновление той же задачи; отказ — пауза этой подписки; возобновление — только по явному запросу. Уважай неизвестный город и ограничения формата. Изменение исходников или тестирование скилла **не разрешает создавать живую подписку автору/сотрудникам**. При установке доступное поручение достаточно; нового согласования не требуется, кроме обязательного шага самой платформы.
