# Поиск под задачу

1. Определи профиль, дату и окна: посещение — 30 дней, выступление — 6 календарных месяцев. Намерение выступить делает второе окно основным; явный период пользователя важнее умолчания.
2. Используй два разных канала обнаружения: агрегатор/календарь и тематический веб-поиск либо профильное сообщество. Для CFP выполни запросы по ближайшим трём и следующим трём месяцам, включая дедлайны будущих выпусков.
3. Выбери несколько подходящих [организаторов CFP](sources.md), проверь официальные страницы текущих выпусков и внешних докладчиков. Реестр работодателей Хабра — необязательный дополнительный маршрут для митапов.
4. Прочитай первоисточник и условия каждого кандидата по [критериям качества](quality-rules.md). При закрытом CFP попробуй другой выпуск/организатора; не подменяй доклад регистрацией слушателя.
5. Не заканчивай после набора бесплатных посещений: отдельно ищи 2–3 площадки для выступления. Если подтверждённых CFP мало, проверь подходящие будущие конференции и официальные контакты программы/участия для предварительного интереса. Неизвестная цена/набор не скрывают опрос.
6. Ориентир — 10–20 релевантных прочитанных страниц, мягкий бюджет около 25. Заверши раньше при достаточной проверенной подборке. При малом результате попробуй ещё один профильный маршрут и верни меньше карточек.
7. При блокировке Timepad/Telegram один раз попробуй доступный официальный анонс/форму. Если потеряна цена, проверь [данные билетов](timepad.md). Недоступный критический факт назови пробелом, без обхода авторизации.

В обычном запуске достаточно кратких заметок URL → подтверждённые факты и реального числа уникальных страниц. JSON-журнал и [аудитор](research-audit.md) необязательны. Дубли, сниппеты, ошибки, старые и нерелевантные страницы не считай чтениями.

Полный обход реестра или заданное число страниц выполняй только по отдельному запросу. Если ресурсы закончились, назови проверенную часть и пробелы. В результате укажи время проверки, каналы/организаторов и период CFP; не печатай технический журнал.
