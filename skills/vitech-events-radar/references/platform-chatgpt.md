# ChatGPT

Для двух вопросов используй доступный нативный инструмент выбора по его фактической схеме. Если клиент поддерживает GenUI `ask_user_input`, выведи два `single_select` (площадка + skip, идея есть/нет), 2–10 вариантов и `free_text_placeholder`. Перед формой — короткое приглашение. Неподдерживаемый виджет замени двумя текстовыми вопросами. В фоне интерактивный вызов не нужен.

Текст обращения помести в нативный writing block/Copy, если доступен; иначе fenced-блок `text`, затем контакты. Подбирай длину ограждения, если тема содержит обратные кавычки.

Для ежемесячной сводки после согласия используй доступные Automations: прочитай задачи с паузами, исключи дубли, создай/обнови одну подписку и перечитай состояние. Схему инструмента получи в текущем окружении. Согласие, настройки и маркеры — по references/monthly-digest.md; наличие ChatGPT само по себе не доказывает доступность scheduler.

Опрос о выступлении обязателен после двух подборок, кроме явного отказа/уже полученных ответов. При нуле площадок замени выбор конференции на помощь Олега с поиском (да/пока нет), сохрани вопрос об идее. Перед вызовом инструмента покажи подборки. Если схема инструмента вмещает меньше вариантов, используй текстовый выбор с исходными номерами. Не заменяй опрос предложением подписки.
