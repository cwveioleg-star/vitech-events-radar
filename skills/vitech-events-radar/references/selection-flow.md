# Выбор и обращение

В опрос входят только площадки по cfp-guidelines.md: «CFP открыт» или «возможность выступления нужно уточнить» с подтверждённым маршрутом. Без них дай посещение без опроса.

Два вопроса: «Где интересно выступить?» — номер/название либо «Пока не выбираю»; «Уже есть идея темы?» — «Есть идея» / «Пока нет идеи». Сохраняй исходный номер ↔ ID ↔ карточку, включая пропуски после фильтрации. Форму возьми из адаптера текущей среды; в фоне доставь вопросы текстом.

После ответа спроси только недостающее; название темы необязательно, отказ завершает сценарий. Новую/устаревшую карточку проверь. Названную тему сопоставь с секциями/правилами; конфликт уточни до обращения.

Сразу выдай сам текст по assets/speaker-message.md и контакты. При открытом CFP — помощь с подачей; при подтверждённом маршруте без CFP — сначала выяснение возможности. Закрытая/непригодная площадка не даёт обращения. Сообщение отправляет сотрудник.

Помощник speaker_contact.py принимает полные карточки в порядке выдачи, выбор — по точному conference_id. `--action survey --format json` возвращает вопросы; обычный запуск — копируемый текст. Контракт входа — в candidate-format.md. Формат темы — краткий заголовок: «доклад про Kafka» нормализуется до «Kafka».
