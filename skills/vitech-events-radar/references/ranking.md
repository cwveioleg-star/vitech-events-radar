# Личная релевантность

Сначала жёсткие фильтры качества: бесплатно, русский язык, российское техническое сообщество, доступность, актуальность; для CFP — открытый приём. Затем ранжирование: прямое совпадение с ролью и текущим стеком, интересами, уровнем/опытом, удобной географией и форматом. Каждой рекомендации дай одно конкретное объяснение пользы.

Не распределяй карточки по направлениям всей компании, не обеспечивай редакционный баланс и не подставляй приоритеты автора. У сотрудника могут быть интересы вне публичного стека компании.
