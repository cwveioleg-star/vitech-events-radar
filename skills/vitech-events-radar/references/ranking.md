# Личная релевантность

После [проверки качества](quality-rules.md) ранжируй по совпадению с ролью, стеком, интересами, опытом, географией и форматом. Для выступления учитывай секции, доступный маршрут подачи и время на подготовку; для посещения — практическую пользу. Каждой карточке дай одну конкретную причину выбора. Интересы сотрудника важнее общего профиля компании.
