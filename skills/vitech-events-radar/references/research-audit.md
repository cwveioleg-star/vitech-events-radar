# Опциональный аудит заявленного поиска

Обычная подборка не требует JSON-журнала или запуска аудитора. Этот контракт нужен для отладки и явно запрошенного полного обхода. Аудитор проверяет самосогласованность предоставленных записей, не подтверждает реальное чтение веба или полноту рынка.


Веди краткий временный журнал вне скилла/GitHub, без личных данных: URL, время чтения, инструментальная ссылка и подтверждённые факты. Считай уникальные канонические документы; убирай UTM, фрагменты, пагинацию одной ленты, зеркала и редиректы. Сниппеты, ошибки, captcha, пустые страницы, старые/нерелевантные анонсы не считаются. Поисковый запрос помогает обнаружению, но не считается прочитанной страницей.

При необходимости используй `scripts/research_audit.py журнал.json --now ISO8601`. Он проверяет предоставленный журнал, не ходит в сеть и не доказывает фактическое чтение. Минимальной квоты по умолчанию нет; поле minimum_reads задаётся только под явный запрос. Короткий синтетический пример структуры:

```json
{
  "mode": "targeted",
  "selected_brand_ids": ["habr-001"],
  "reads": [{"url":"https://example.org/events","brand_ids":["habr-001"],"kind":"calendar","status":"read","relevant":true,"checked_at":"2026-10-15T09:00:00+03:00","tool_ref":"synthetic-read","evidence":"Синтетические данные, не чтение"}],
  "discovery_searches": [
    {"kind":"aggregator","checked_at":"2026-10-15T09:00:00+03:00","tool_ref":"synthetic-1","evidence":"Календарь"},
    {"kind":"web","checked_at":"2026-10-15T09:00:00+03:00","tool_ref":"synthetic-2","evidence":"Тематический поиск"}
  ],
  "brand_checks": [{"brand_id":"habr-001","checked_at":"2026-10-15T09:00:00+03:00","cfp_from":"2026-10-15","cfp_through":"2027-04-15","routes":[
    {"kind":"calendar","status":"read","read_indices":[0],"tool_ref":"synthetic-read","evidence":"Официальный календарь"},
    {"kind":"cfp","status":"not_found","tool_ref":"synthetic-search","evidence":"Поиск текущих выпусков и CFP за весь период"}
  ]}],
  "cfp_search": {"from":"2026-10-15","through":"2027-04-15","community_searches":[{"tool_ref":"synthetic-cfp","evidence":"Темы, обе части периода и независимые сообщества"}],"unresolved":[],"verified_suitable_count":0}
}
```

`mode=full` означает полный обход рабочего реестра по отдельному запросу. Обычный режим требует только объявленные selected_brand_ids. Если бренды не выбирались, явно передай пустой список и опиши охват агрегаторов/сообществ. Основные маршруты — calendar и cfp; timepad/telegram необязательны. Успех аудитора относится только к заявленному плану, а не ко всем событиям рынка.

Текущий список можно передать в `registry`: source_url, checked_at, tool_ref, evidence, brands с уникальными id/name. При чтении актуальной страницы используй её состав, а не жёсткое число 126. Без registry helper использует датированный локальный снимок и сообщает это в результате. Не выдавай fallback за обновлённый список. Дополнительные сообщества — extra_brands с уникальными id/name. Все инструментальные чтения/проверки не старше суток и не из будущего. Старый JSON-массив поддерживается для подсчёта документов, но не подтверждает план поиска.


Полный свежий registry должен содержать весь прочитанный список. Аудитор сравнивает его размер со снимком: сокращение более чем вдвое считается подозрительным и отклоняется. Для выборочного поиска передавай selected_brand_ids, а не урезанный registry. Успешная проверка свежего trace не доказывает истинность реестра.
