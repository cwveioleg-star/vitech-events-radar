# Техбренды и открытые маршруты поиска

База охвата — [полный список брендов из рейтинга Хабра](https://habr.com/ru/specials/965986/). Машиночитаемый снимок названий: [tech-brands.json](tech-brands.json), 126 записей из общего списка на 15.10.2026. Это список организаторов для поиска, не подтверждение мероприятий и не рейтинг рекомендаций.

При каждом запуске открой исходную страницу, проверь изменения и составь рабочий реестр всех брендов. Повторные таблицы по отраслям/численности не создают новые записи. При недоступности страницы используй снимок с указанием даты. Новые обнаруженные бренды и профильные сообщества добавляй к охвату; список не ограничивает поиск.

У всех брендов одинаковый статус. Порядок в рейтинге не определяет внимание к компании или место события в рекомендациях. Разные подразделения сохраняй отдельными записями; общий канал можно связать с несколькими брендами только при подтверждении их связи.

Для **каждой записи** проверь маршруты:
1. Официальный технический сайт, календарь, сообщество и текущие анонсы.
2. Timepad и другие публичные регистрации; сверяй организатора по его официальным ссылкам.
3. Публичные Telegram-каналы и посты технического сообщества, ссылки из официальных страниц. Не используй личные переписки.
4. CFP: «приём докладов», «стать спикером», «подать доклад», формы предложений тем и анонсы будущих выпусков на весь горизонт поиска.

Поиск не ограничивается доменом компании: используй открытые календари, Timepad, публичный Telegram, Habr, страницы сообществ и независимых конференций. Из поисковой выдачи переходи к документу; индекс или сниппет помогает обнаружению, но не заменяет чтение.

Профиль сотрудника определяет глубокую проверку секций и итоговые рекомендации. Неподходящее направление бренда не повод пропустить поиск его инженерных мероприятий. Если маршрута не найдено, зафиксируй запросы и результат. Ошибка чтения, 502 или закрытый канал — пробел проверки; ищи альтернативный официальный анонс. Не конструируй адреса по названию.

Профильные сообщества Go/PHP/Java/Python, frontend, QA, SRE/DevOps, БД, данных, безопасности и ML ищи отдельно по интересам сотрудника. Платные выпуски и бесплатная подача на платную конференцию не проходят фильтр 0 ₽.
