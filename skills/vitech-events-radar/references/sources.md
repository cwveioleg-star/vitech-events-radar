# Маршруты обнаружения

Начни с доступного [календаря Хабра](https://habr.com/ru/events/), поиска Timepad или тематического поиска CFP. Факты подтверждай у организатора. Публичные Telegram/Timepad необязательны; при блокировке используй официальный сайт. Для Timepad см. [проверку билетов](timepad.md).

## Организаторы конференций и CFP

Это маршруты поиска, а не утверждение об открытом приёме или бесплатности конкретного выпуска. Выбирай по профилю; каждый текущий CFP проверь отдельно.

| Организатор | Где искать | Темы |
|---|---|---|
| Онтико | [ontico.ru](https://ontico.ru/) → текущая конференция → «Подать доклад» | HighLoad++, GolangConf, DevOpsConf, backend/инфраструктура |
| JUG Ru Group | [jugru.org](https://jugru.org/) → конференции → спикерам | Java/JVM, тестирование, frontend, платформы |
| Linkmeup | [linkmeup.ru](https://linkmeup.ru/) → Linkmeetup/анонсы докладов | Сети, протоколы, эксплуатация |
| Флант / Deckhouse | [deckhouse.ru](https://deckhouse.ru/) → события/Deckhouse Conf | Kubernetes, платформы, DevOps |
| Podlodka | [podlodka.io](https://podlodka.io/) → текущая конференция/CFP | Разработка, инфраструктура, архитектура, управление |

Дополняй профильными Go/PHP/Java/Python, QA, SRE/DevOps, БД, data, security и ML-сообществами. Порядок таблицы не задаёт приоритет.

## Необязательный реестр техбрендов

[Рейтинг работодателей Хабра](https://habr.com/ru/specials/965986/) помогает находить корпоративные митапы; читать его при каждом запуске не нужно. [tech-brands.json](tech-brands.json) — датированный снимок, достаточный для выбора нескольких названий без заявления об актуальности полного рейтинга.

При явно запрошенном полном обходе/обслуживании снимка прочитай исходный список; сохрани ID совпавших имён. Выбранные 2–3 бренда не выдавай за полный свежий реестр. Недоступность рейтинга не блокирует CFP. В обычном запуске файлы скилла не меняй.

Подбирай организаторов по роли сотрудника: для DevRel/контента/сообществ дополнительно проверяй DevRel Conf, IT HR Hub/HR42; для обучения — профильные L&D/EdTech-события. Не своди любой профиль к облакам/backend. Для предварительного интереса читай официальный контакт по программе/участию и помечай неизвестные условия.
