# Маршруты поиска, а не готовая подборка

Каждый запуск заново проверяй актуальные календари и прямые формы. Наличие бренда в этом списке не подтверждает бесплатность, язык или открытый CFP конкретного события.

Обязательные техбренды:
- [AvitoTech](https://avito.tech/): раздел «Мероприятия», затем анонс и прямая регистрация. Связанные Timepad/Telegram проверяй по ссылке организатора.
- [Alfa Digital](https://digital.alfabank.ru/events): инженерные митапы по backend, QA, данным и другим личным интересам. Архив не означает действующий приём.

Другие направления охвата: Яндекс, Т-Банк, Сбер, VK Tech, Ozon Tech, Wildberries/Russ, Lamoda Tech, X5 Tech, Магнит Tech, МТС, 2ГИС, Контур, Selectel, Cloud.ru, Positive Technologies, Kaspersky, JetBrains русскоязычные сообщества, Додо, hh.ru, ЮMoney, Циан, Райффайзен Tech, Газпромбанк Tech, Ростелеком, РТК ИТ, Beeline, Астра, Postgres Professional, YADRO, Тензор, KODE, AGIMA, Evrone, Usetech, Naumen.

У этих брендов ищи **официальный текущий календарь/сообщество** и связанные организатором публичные анонсы. Не конструируй URL из названия и не считай бренд автоматически проверенным. Если бренд проводит только платное/англоязычное событие — исключи мероприятие, продолжи поиск.

Профильные сообщества и конференции: Go, PHP, Java, Python, frontend, QA/автотесты, DevOps/SRE, PostgreSQL, Kafka, аналитика, безопасность и ML — только по профилю сотрудника. HighLoad, Heisenbug, JPoint, Joker, TeamLead Conf, DUMP и Merge можно использовать для обнаружения тем/CFP, но многие выпуски платные: без подтверждения 0 ₽ нужного формата не рекомендовать.

Агрегаторы и каталоги Timepad, Habr Events, IT Event Hub помогают обнаружить анонс; окончательное решение — по организатору и прямой форме. Один календарь со 100 строками не равен 100 прочитанным источникам. Старые примеры не являются текущими рекомендациями.
