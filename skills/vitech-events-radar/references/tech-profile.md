# Только публичный профиль компании

Ви.Tech — команда, которая разрабатывает IT-продукты для ВИ.ру / ВсеИнструменты.ру. Контекст для поиска: разработка продуктов электронной торговли и инженерная инфраструктура.

Публично перечислены Go, PHP, Vue.js, TestRail, Docker, Kubernetes, PostgreSQL, MySQL, ClickHouse, Redis, Kafka, Prometheus, Jaeger, Grafana и GitLab. Это перечень компании, а не стек каждого сотрудника.

Источник: [официальный сайт](https://vitech.team/), блоки «IT-продукты для ВИ.ру» и «Наш стек», проверено 15.10.2026.

Выбирай направления по роли, стеку и интересам самого сотрудника. Публичный список технологий компании не заменяет личный профиль.
