# Другой агент или клиент

Используй фактически доступный нативный question/choice tool; без него — два коротких текстовых вопроса с номерами и возможностью отказаться. Копируемое обращение — fenced-блок `text`, затем контакты.

Ежемесячную сводку создавай только после согласия и проверки постоянного scheduler с веб-доступом, чтением прежних задач и повторным чтением сохранённого состояния. Имя IDE, установленный скилл и Python-helper не подтверждают наличие этой возможности. Без неё выполни разовую подборку и назови конкретное ограничение. Системный cron, GitHub Actions и сторонние сервисы не настраивай без отдельного поручения.
