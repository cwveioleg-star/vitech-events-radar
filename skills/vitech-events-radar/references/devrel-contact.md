# Контакт для обращения после выбора конференции

Единственный источник разрешённых контактов Олега. Обращение готовится после ответа сотрудника; отправку выполняет сам сотрудник.

```json
{
  "greeting": "Олег, привет!",
  "loop_label": "Написать Олегу в Loop",
  "loop_url": "https://msg.vseinstrumenti.ru/vitech/messages/@buselov",
  "telegram_url": "https://t.me/oleg_busel"
}
```

Сначала копируемый текст, сразу под ним Loop и Telegram. Не читать переписку по этим ссылкам. Не добавлять биографию, задачи, стиль, стратегию или рабочие документы получателя. Адреса не использовать для автоматической отправки.
