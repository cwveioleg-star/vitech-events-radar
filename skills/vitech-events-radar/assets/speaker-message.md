# Текст после выбора

Для подтверждённого открытого CFP:

```text
Олег, привет!
Хочу выступить на конференции «{название}».
{Фраза об идее}.
Помоги, пожалуйста, собрать фактуру и подготовиться к подаче.
Конференция: {ссылка}
CFP: {открытая форма}
```

Для подтверждённого маршрута внешних докладов без открытого CFP:

```text
Олег, привет!
Мне интересно выступить на событии «{название}».
{Фраза об идее}.
Открытый приём докладов пока не подтверждён.
Помоги, пожалуйста, выяснить, возможно ли участие как спикера, и, если возможно, собрать фактуру.
Конференция: {ссылка}
Спикерам: {официальный маршрут}
```

Фраза: «У меня уже есть идея темы» / «Пока нет идеи темы»; при названной подходящей теме — «Идея темы: {краткий заголовок}». В готовом тексте выбери одну фразу без слеша и скобок. Сразу под блоком дай Loop/Telegram из references/devrel-contact.md. Сообщение отправляет сотрудник.
