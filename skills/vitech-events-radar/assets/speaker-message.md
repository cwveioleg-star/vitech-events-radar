# Текст после опроса

```text
Олег, привет!
Хочу выступить на конференции «{проверенное название}».
{У меня есть идея темы: «названная публичная тема». / У меня уже есть идея темы. / Пока нет идеи темы.}
Помоги, пожалуйста, собрать фактуру и подготовиться к подаче.
Конференция: {прямая ссылка}
CFP: {проверенная открытая форма}
```

Выбери одну фразу о теме по ответу сотрудника; не показывай фигурные скобки или варианты через слеш. Затем выведи основной Loop и Telegram из references/devrel-contact.md. Тема, кейсы, должность, имя и показатели не угадываются. Подготовка черновика после опроса не требует повторного разрешения. Отправки нет.
