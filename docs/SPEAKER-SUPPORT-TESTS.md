# Проверки выбора и обращения

Проверяются два single_select с номерами/ID, открытый CFP и подтверждённый маршрут внешних докладов без CFP. Варианты честно отмечают статус; регистрации слушателей не выдаются за подачу доклада. Нет пригодных площадок — два вопроса о помощи с поиском и идее, без фиктивных конференций.

Проверяются фильтры цены/языка/дат, закрытый или устаревший CFP, точное разрешение выбранного ID, оба состояния идеи, необязательное название, отказ, два конфигурируемых контакта, copy block и CLI без повторения ошибочного ввода.

Для открытого CFP текст просит помочь с фактурой и подачей; для подтверждённого маршрута без опубликованного CFP — сначала выяснить возможность. Закрытый приём/программа и мероприятия без внешних докладов не допускаются в опрос. Никакой отправки. Нумерованный ответ сначала сопоставляется со стабильным ID текущей подборки.

Агентные прогоны на сырых синтетических материалах проверяют применение инструкций. Они не заменяют живой поиск и не доказывают видимость кнопок во всех клиентах. Результаты в TEST-REPORT.md.

Отдельные регрессии issue #1: платные слушателю/бесплатные спикеру CFP; 6 календарных месяцев; сохранение исходных номеров после фильтрации; официальная страница спикерам; нормализация «доклад про Kafka»; проверка соответствия названной темы секциям/правилам.

Регрессия v0.8.0: неизвестная цена в speaker_inquiry не убирает площадку из опроса при наличии официального контакта. Compose честно просит уточнить условия, не обещает бесплатность. Известный взнос, закрытый CFP, окончательная программа, просроченный дедлайн, отсутствие контакта/даты/языка исключают вариант, но не fallback-опрос.
