# Проверки выбора и обращения

Проверяются два single_select с номерами/ID, открытый CFP и интерес к событию без CFP. Варианты честно отмечают статус; регистрации слушателей не выдаются за подачу доклада. Нет проверенных событий — нет фиктивных вариантов.

Проверяются фильтры цены/языка/дат, закрытый или устаревший CFP, точное разрешение выбранного ID, оба состояния идеи, необязательное название, отказ, два конфигурируемых контакта, copy block и CLI без повторения ошибочного ввода.

Для открытого CFP текст просит помочь с фактурой и подачей; для неизвестного/закрытого приёма — сначала выяснить возможность выступления. Никакой отправки. Нумерованный ответ сначала сопоставляется со стабильным ID текущей подборки.

Агентные прогоны на сырых синтетических материалах проверяют применение инструкций. Они не заменяют живой поиск и не доказывают видимость кнопок во всех клиентах. Результаты в TEST-REPORT.md.
