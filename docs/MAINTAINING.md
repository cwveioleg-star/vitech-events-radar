# Поддержка скилла

Редактируй правила и источники в skills/vitech-events-radar, обновляй установленный личный скилл штатным способом. Публичный профиль компании сверяй с официальным сайтом. Рекомендации персонализируй по роли, стеку и интересам самого сотрудника.

Проверяй личные роли, недоступную память, неизвестный город, бесплатность/русский язык, платный CFP, прошедшую дату, закрытую форму, ноль результатов, неполный охват 100 источников, всех брендов и шестимесячного горизонта CFP, опрос и оба ответа о теме. Не сохраняй реальные профили и журналы в GitHub. Скрипты офлайн, фактические чтения веба они не доказывают.

Месячный маркер v1 стабилен для дедупликации; политика персонального промпта v3. При обновлении сохраняй ID, личные настройки и паузу. Различай план и реально сохранённую подписку; тесты не создают задач. При новых API/возможностях платформ сверяйся с их текущей официальной документацией.

Проверки: python3 -m unittest discover -s tests -v; python3 tests/validate_structure.py. Существенные изменения проверяй независимым агентом на сырых синтетических данных с минимальным контекстом и без внешних мутаций. Различай такие прогоны, unit-тесты и живое исследование 100 источников.

Обновляй VERSION, CHANGELOG и TEST-REPORT. Выпускай новый тег и ZIP с одним корнем проекта, внутри которого лежит skills/vitech-events-radar. Не перезаписывай прежний релиз. Сообщение об ошибке должно содержать воспроизводимый запрос без личных данных, факт, первоисточник и время проверки.
