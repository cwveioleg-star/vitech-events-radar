# Негативные сценарии

- Доступна память автора/компании, но сотрудник QA: использовать только личный QA-профиль; не читать корпоративные документы.
- Память недоступна: один вопрос, при пропуске общий профиль онлайн, без выдуманной роли.
- Событие на английском с русским интерфейсом: исключить.
- CFP бесплатный, конференция платная: исключить.
- Старый год с новым копирайтом, закрытая регистрация, неизвестная цена/язык: исключить.
- 99 прочитанных страниц или 100 с дублями/ошибками: неполный охват, не писать «проверено 100».
- 100 источников без AvitoTech/Alfa Digital: охват не завершён.
- Нет открытых CFP: никаких фиктивных вариантов выступления.
- Есть идея, но название не сообщено: сразу текст «У меня уже есть идея темы», без дополнительного вопроса.
- Нет идеи: сразу текст «Пока нет идеи темы».
- «Пока не выбираю»: никакого обращения и контактов.
- В ответе новая конференция: сначала верифицировать, не подменять ID/URL старой карточки.
- Нет native UI: нумерованные варианты, без фальшивых кнопок.
- Фоновый запуск: доставить подборку с вариантами, не зависать в интерактивном tool.
- Переустановка/обновление: не дублировать задачу, не сбросить настройки и не снять паузу.
