# Негативные сценарии

- Память недоступна: один вопрос; при пропуске общий профиль онлайн, без выдуманной роли.
- Профиль QA/API: рекомендации определяются его личными интересами.
- Английские доклады с русским интерфейсом, неизвестная цена/язык, бесплатный CFP на платную конференцию: исключить.
- Старый выпуск с новым копирайтом, закрытая регистрация: исключить.
- 99 прочитанных страниц или 100 с дублями/ошибками: не писать «проверено 100».
- 100 страниц при пропущенных брендах: считать чтения отдельно, назвать пробелы охвата.
- Список Хабра или один календарь со 100 строками: один документ, не сотня чтений.
- 502 и поисковый сниппет: не подтверждают актуальное состояние календаря.
- Один месяц CFP или неразрешённые маршруты: нельзя говорить, что подходящих открытых конференций нет.
- Полный охват шести месяцев без подходящего CFP: допустим ограниченный вывод с явным интервалом.
- Проверенное событие без CFP: предложить выразить интерес к выступлению; обращение условное.
- Закрытый CFP: статус назвать прямо, не обещать подачу.
- Есть идея без названия: сразу «У меня уже есть идея темы».
- Нет идеи: сразу «Пока нет идеи темы».
- «Пока не выбираю» или «только посетить»: не готовить обращение о выступлении.
- Новая конференция/URL в свободном ответе: сначала проверить отдельно.
- В двух разделах подборки: единая сквозная нумерация, соответствующая опросу.
- Нет native UI: два текстовых вопроса без фальшивых кнопок.
- Фоновый запуск: доставить варианты, не ждать интерактивный ответ.
- Переустановка/обновление: сохранить ID, время, профиль и паузу, не создавать дубли.
