# Проверка v0.5.1

Дата: 15.10.2026. Пройдены все 85 unit/CLI-проверок, проверка структуры и относительных ссылок, quick_validate.py и git diff --check. Вспомогательные скрипты и сценарий поиска событий не менялись.

Обновлены правила установки и обновления: выбор агента/версии/scope, одна подтверждённая установка, сохранение ID, проверка пути и ссылок, резервная копия, сохранение локальных/неизвестных файлов и ограниченный список удалений по проверенной предыдущей версии. README и SKILL ссылаются на один протокол. Примеры Codex, Claude Code, Cursor, Copilot и Gemini сверены с официальной документацией; перед установкой требуется повторная проверка возможностей конкретного клиента.

## Независимый агентный прогон

Один свежий агент получил README, протокол и три сырых синтетических сценария без ожидаемых ответов. Он составил планы без изменения файлов и внешних систем:

1. Claude Code с неизвестным пользовательским файлом, изменённым ресурсом, неизменённым устаревшим файлом и внешним симлинком: пользовательские данные сохранены, удаление допускается только для подтверждённого неизменённого ресурса, запись через ссылку исключена, конфликты названы.
2. Cursor Cloud с локальной `.agents/skills` и неизвестным механизмом доставки: локальная папка не объявлена облачной установкой, назван конкретный блокер.
3. Неизвестная старая версия и пользовательский файл на пути нового ресурса: автоматическое удаление запрещено, перезапись не выполняется молча, частичный результат не назван завершённым обновлением.

## Пределы проверки

Это проверка инструкций, а не выполнение установщика на компьютерах пользователей. В этой версии не добавлен автоматический установщик и не выполнялась матрица живых установок во всех клиентах и ОС. Обнаружение скилла, разрешения и фоновый запуск проверяются в фактической среде при установке. Новые подписки и сообщения при разработке не создавались.

# Проверка v0.5.0

Дата: 15.10.2026. Пройдены 85 unit/CLI-проверок, проверка структуры/ссылок, валидатор скилла и git diff --check.

Проверены независимо: число реально учтённых страниц, охват всех 126 записей реестра, маршруты calendar/Timepad/публичный Telegram/CFP, шестимесячный горизонт с переходом года. Сто страниц при пропущенных брендах, сокращённый период, 502/сниппет, чужой или непрочитанный документ и пробел по сообществам не позволяют общий отрицательный вывод о CFP. Проверены границы календарных месяцев и явное сужение до четырёх месяцев; три месяца недостаточно.

Опрос включает проверенные события с разными статусами выступления и сохраняет единые номера. Проверены открытый CFP, неизвестный/закрытый приём, оба ответа об идее, необязательное название темы, отказ, устаревшая карточка, точные контакты и CLI. Событие без CFP даёт условное обращение, без обещания подачи и без ссылки на регистрацию слушателя под видом CFP.

Месячный промпт v3 содержит полный снимок реестра и самостоятельные правила поиска, горизонта, неполного охвата, опроса и двух вариантов обращения. Сохранены тесты дедупликации, личных настроек, паузы, отказа и планировщика.

## Независимые агентные прогоны

Три свежих агента получили скилл, обычный запрос и сырые синтетические входные материалы без ожидаемого ответа. Ничего во внешних системах не меняли.

1. Активация с QA/API-профилем, одним проверенным брендом и месяцем CFP: показаны неполнота охвата и требуемый горизонт до 15.04.2027, общего вывода об отсутствии CFP нет; предложены событие и два вопроса.
2. Материалы со всеми брендами и шестимесячным интервалом: агент отделил синтетический журнал от реальных чтений, не выдал его за актуальный календарь и сохранил приглашение выбрать событие.
3. Ответ «выбираю 1, идеи нет» для события без CFP: сразу условный копируемый текст Олегу и Loop/Telegram, без уточнения темы и без ложного обещания подачи.

## Пределы проверки

Реестр названий извлечён из общего списка указанной страницы Хабра; повторные отраслевые таблицы не включены второй раз. Живой обход всех календарей и поиск 100 мероприятий в рамках разработки не проводились. Unit-тесты проверяют предоставленные записи, а не истинность веб-фактов. Агент будущего запуска обязан действительно читать источники.

Отображение native UI и Copy зависит от клиента; предусмотрен текстовый запасной вариант. Реальные подписки, сообщения, регистрации и заявки при изменении версии не создавались.

В предыдущей версии проходила 71 проверка персонализации, фильтров, учёта чтений, опроса, контактов и месячного цикла. Новые проверки расширяют этот набор.
