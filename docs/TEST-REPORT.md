# Проверка v0.6.0

Дата: 15.10.2026. Пройдены 101 unit/CLI-проверка, проверка структуры и локальных ссылок, quick_validate.py и git diff --check. Основной SKILL.md: 16953 → 8520 байт, description — 227 символов. Изменены инструкции, аудит поиска и планировщик подписки; фильтры карточек и helper обращения сохранены.

## Что проверено

- Обычный объявленный план с 12 уникальными чтениями и тремя выбранными организаторами может завершиться без квоты 100 и обхода всех брендов. Явный minimum_reads=100 продолжает требовать 100; режим full проверяет весь рабочий список. Дубли, сниппеты, блокировки и старые чтения не увеличивают счётчик.
- Timepad/Telegram необязательны: недоступный дополнительный маршрут не отменяет подтверждённый официальный источник; пробел в основном источнике не скрывается. Два канала обнаружения, период CFP, выбранный scope и реальные следы чтения проверяются отдельно. Аудит не разрешает общий вывод об отсутствии CFP на всём рынке.
- Рабочий registry может отличаться размером от снимка; проверяются URL/свежий след, уникальность id/name и выбранные бренды. Снимок явно маркируется датой fallback. Структурная проверка не фиксирует число 126.
- Новая задача без monthly_enabled=true возвращает consent_required без task/tool_arguments. Явное согласие допускает план create с записью согласия. Legacy-задача без подтверждения не мигрируется и не отключается автоматически. Сохранены проверки дублей, паузы, ID, профиля, индивидуального времени, зоны/DST, readback-контракта и запрета создания по одному resume без старой задачи.
- Строгие условия будущей даты, русского языка, 0 ₽ нужного формата, регистрации/CFP и двух вариантов обращения проверяются прежними тестами.

## Независимые агентные прогоны

Два свежих агента получили скилл и обычные задачи на сырых синтетических данных без ожидаемых ответов. Внешние изменения запрещены.

1. Подборка QA/API по 12 страницам, двум каналам, трём выбранным организаторам из рабочего списка 128 имён; Timepad/Telegram заблокированы, официальный источник доступен. Агент дал два проверенных по сценарию варианта без требования дочитать 100, обозначил синтетический характер, провёл два вопроса и после «1, идеи нет» сразу подготовил условное обращение без обещания открытого CFP. Свое согласие на сводку не подставлял.
2. Месячный helper локально запущен для «установи» без ответа, явного «да, включи» и старой активной задачи без подтверждения. Получены соответственно consent_required, create-план и consent_required. Агент отделил план от реальной подписки и сохранил старые настройки.

## Пределы проверки

Это проверка кода и поведения на синтетических материалах. Реальные подписки, сообщения, регистрации и заявки не создавались и не менялись. Массовый поиск мероприятий, матрица всех агентов/ОС и полный обход брендов в ходе разработки не проводились. Аудитор проверяет введённые записи, а не истинность веб-фактов; будущий запуск обязан читать источники. Безопасность обновления остаётся протоколом агента, не файловой песочницей.

# Проверка v0.5.1

Дата: 15.10.2026. Пройдены все 85 unit/CLI-проверок, проверка структуры и относительных ссылок, quick_validate.py и git diff --check. Вспомогательные скрипты и сценарий поиска событий не менялись.

Обновлены правила установки и обновления: выбор агента/версии/scope, одна подтверждённая установка, сохранение ID, проверка пути и ссылок, резервная копия, сохранение локальных/неизвестных файлов и ограниченный список удалений по проверенной предыдущей версии. README и SKILL ссылаются на один протокол. Примеры Codex, Claude Code, Cursor, Copilot и Gemini сверены с официальной документацией; перед установкой требуется повторная проверка возможностей конкретного клиента.

## Независимый агентный прогон

Один свежий агент получил README, протокол и три сырых синтетических сценария без ожидаемых ответов. Он составил планы без изменения файлов и внешних систем:

1. Claude Code с неизвестным пользовательским файлом, изменённым ресурсом, неизменённым устаревшим файлом и внешним симлинком: пользовательские данные сохранены, удаление допускается только для подтверждённого неизменённого ресурса, запись через ссылку исключена, конфликты названы.

3. Неизвестная старая версия и пользовательский файл на пути нового ресурса: автоматическое удаление запрещено, перезапись не выполняется молча, частичный результат не назван завершённым обновлением.

## Пределы проверки

Это проверка инструкций, а не выполнение установщика на компьютерах пользователей. В этой версии не добавлен автоматический установщик и не выполнялась матрица живых установок во всех клиентах и ОС. Обнаружение скилла, разрешения и фоновый запуск проверяются в фактической среде при установке. Новые подписки и сообщения при разработке не создавались.
