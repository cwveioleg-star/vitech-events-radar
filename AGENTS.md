# Инструкции агентам

Если пользователь прислал ссылку и написал «установи», выполни инструкцию README сам. Источник — вся папка skills/vitech-events-radar; имя из frontmatter — vitech-events-radar. Выбери личное хранилище текущей платформы, обновляй существующий скилл в его папке, проверь доступность и запусти первую подборку. Личную месячную задачу по references/monthly-digest.md создавай только после отдельного явного согласия; «установи» его не заменяет. Отказ, индивидуальное время и паузу уважай. Клонирование или импорт ZIP сами по себе не создают расписание.

До записи прочитай [протокол установки](skills/vitech-events-radar/references/install-update.md). Определи конкретного агента и его возможности, не угадывай путь по названию IDE. Проверяй точную установку и `name` в её `SKILL.md`; сохраняй локальные правки, неизвестные файлы и идентичность скилла. Не удаляй папку скилла целиком, общие roots или соседние скиллы; не следуй ссылкам за пределы выбранного каталога. Удаление возможно только по подтверждённому составу предыдущей версии для локально неизменённых файлов. Skill Creator нужен только в среде, где это штатный доступный механизм.

При активации сразу выполняй личный сценарий SKILL.md: нативная память самого сотрудника → бесплатные слушателю русскоязычные события → агрегаторы/тематический поиск → выбранные организаторы и первоисточники → возможности выступить бесплатно для спикера на шесть месяцев → два вопроса об интересе к выступлению и идее → обращение после ответа. Для персонализации используй роль, стек, интересы и город самого сотрудника из его доступной памяти или ответов. Ориентир поиска 10–20 страниц без обязательной квоты; полный обход только по запросу. Рейтинг работодателей Хабра необязателен; для CFP выбирай профильных организаторов из references/sources.md. Подробный JSON-аудит необязателен. Всегда завершай двумя вопросами, кроме отказа или уже полученных ответов. В опрос входят открытые CFP, подтверждённые маршруты и предварительные площадки с официальным контактом; неизвестную цену/набор обозначай явно. При нуле площадок предложи помощь Олега с поиском, затем спроси об идее. Закрытые CFP, окончательные программы и известный взнос спикеру исключай. Платный билет слушателю не исключает бесплатное участие принятого спикера. Читай только адаптер текущей платформы. Timepad/Telegram необязательны. Объём не заменяет подтверждение фактов.

При изменении исходников поддерживай установленный личный скилл и переносимую папку skills/vitech-events-radar. Корневые README/CHANGELOG/docs/tests не устанавливать как ресурсы скилла. Контакты централизованы в references/devrel-contact.md; только Loop/Telegram, без автоотправки.

Перед публикацией: python3 -m unittest discover -s tests -v; python3 tests/validate_structure.py; обнови VERSION/CHANGELOG/отчёт и проверь архив. Публикация по docs/PUBLISH.md, текущий remote head и safe lease. Изменение или тестирование исходников само по себе не создаёт подписки.
