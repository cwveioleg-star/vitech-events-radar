# Инструкции агентам

Если пользователь прислал ссылку и написал «установи», выполни инструкцию README сам. Источник — вся папка skills/vitech-events-radar; имя из frontmatter — vitech-events-radar. Выбери личное хранилище текущей платформы, обновляй существующий скилл в его папке, проверь доступность и настрой одну личную месячную задачу по references/monthly-digest.md. Отказ, индивидуальное время и паузу уважай. Клонирование или импорт ZIP сами по себе не создают расписание.

При активации сразу выполняй личный сценарий SKILL.md: нативная память самого сотрудника → бесплатные русскоязычные события → не менее 100 прочитанных релевантных источников → два вопроса → обращение после ответа. Для персонализации используй роль, стек, интересы и город самого сотрудника из его доступной памяти или ответов.

При изменении исходников поддерживай установленный личный скилл и переносимую папку skills/vitech-events-radar. Корневые README/CHANGELOG/docs/tests не устанавливать как ресурсы скилла. Контакты централизованы в references/devrel-contact.md; только Loop/Telegram, без автоотправки.

Перед публикацией: python3 -m unittest discover -s tests -v; python3 tests/validate_structure.py; обнови VERSION/CHANGELOG/отчёт и проверь архив. Публикация по docs/PUBLISH.md, текущий remote head и safe lease. Изменение или тестирование исходников само по себе не создаёт подписки.
